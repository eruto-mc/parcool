> | ⚠⚠ **スライディングで坂を滑り降りられるようにした**（速さを物理の式で育て、滑っている間は段差を登らせない） | ⚠ 上流は毎ティック水平速度を**固定値で書き直す**ので坂でも平地でも同じ速さで、しかも接地していないティックは 0.6 倍。段差は落ちる間ずっと浮くので、⚠ **階段を下ると速くなるどころか遅くなっていた**。いまは「下がった高さ ÷ 進んだ水平距離」から坂の急さを出し、`加速度 = 0.08 × (sinθ − 0.1 × cosθ) − 0.12 × v²` で速さを育てる。⚠⚠ **末尾の v² の項が「落ち着く速さ」を坂ごとに決める**（26.6度で 9.8 m/s・45度の階段で 13.0 m/s・63.4度で 15.1 m/s）——⚠ **2026-09-04 まではこの項が無く、傾きが 5.7 度を超える坂はどれも 10 tick 弱で上限に張り付いて、どの坂でも同じ 18 m/s だった**。上限 0.8（＝16 m/s）はいまは安全弁で、普通の地形では当たらない。⚠ 坂を滑っているティックは持ち時間から差し引くので、坂が続く限り滑れる |

> | ⚠ **ジップラインを滑っている間の音を足した**（バニラのエリトラの滑空音を `sounds.json` から借りる） | 上流はロープを張る音と外す音しか持たず（[#433](https://github.com/alRex-U/ParCool/issues/433) で要望が出たまま）、⚠ **320 ブロックまで伸ばした当部では無音の時間が目立つ**。速さに合わせて音量と高さが変わる。⚠ **新しい音のファイルは足していない**（ジャスト受け身と同じやり方）。⚠ **鳴らすのは自分が乗っているときだけ**——他人のぶんは `speed` が同期されていない |
> | ⚠⚠ **移動キーの向きを、キーの押下から先に読むようにした** | ⚠⚠ **三人称では回避が一度も出ていなかった**。Better Third Person がカメラの向きへ体を向けるために `player.input` を**毎ティック書き換える**（上流 [#383](https://github.com/alRex-U/ParCool/issues/383)。ソースが公開されておらず上流も直せていない）ので、⚠ **S を押しても「前向き」と読めていた**。回避は S / A / D の二度押しでしか出ないので、どれも発火しない。⚠ **キーが押されていないときは従来どおり `input` を見る**——ゲームパッドの入力はキー割り当てを通らないため。⚠ 回避が飛ぶ向きも押したキーから組み直す |
>
> ⚠ **高さの定数は体格でスケールする**（種族で大きさが違う）。⚠⚠ **立ち高さのほうを見ること**——滑っている間は姿勢が泳ぎ姿勢なので、`getBbHeight()` だと**姿勢の低さを体格と取り違える**。
>
> ⚠ **地面への吸着は作って外した**（2026-09-03）。理由は `Slide.java` のコメントに残してある——
> 中心1本のレイで地面を探すと段の縁で誤り、**体が手前の段へめり込んで下りで引っかかる**。
>

# ParCool MOD

**Welcome to this project!**

*ParCool* is a mod of Minecraft, for more *Cool* Actions like *Parkour*.  
It's inspired by [SmartMoving](https://www.curseforge.com/minecraft/mc-mods/smart-moving). That was a very great mod.

Players can do more actions such as...

+ Grabbing Cliffs
+ Running Faster
+ Roll
+ Backflip
+ WallJump
+ CatLeap  
  etc

If it made you traceurs or traceuses ; parkour practitioners, I couldn't be happier!!

This project is always ready to accept your contribution.

### For Developers

This mod provides some features for mod developers, server-hosts and mod-packers.

## `parcool:parkour` — パルクールを人ごとに止める（eruto_patch=4）

素の ParCool は**サーバ全体**（`permit_*`）か**その人の設定**（`can_*`）でしか
可否を決められず、⚠ **種族で分ける口が無かった**。

`ActionProcessor.checkAndChangeActionState` は、⚠ **すべての技が通る唯一の関所**
（`InstantAction` も含めて `parkourability.getList()` の1本の for から来る）。
そこで属性を1回読み、**始めるほうと続けるほうの両方**を止める。

| 値 | 意味 |
| - | - |
| 1.0（既定） | 素の ParCool のまま |
| 0.0 | パルクールを一切しない |

⚠ Origins からは `origins:attribute` 1枚で当てられる。
当部ではゴーレムに 0.0 を当てている（重い体でよじ登らない）。
